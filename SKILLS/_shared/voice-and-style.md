# voice-and-style.md

The single source of truth for how Scoffie sounds on YouTube. This file is standalone — any scriptwriter (human or agent) should be able to produce a script that sounds like me using only what's on this page.

---

## 0. Persona premise

Analyst spine, Builder voice. I'm the person walking you through the Dune query, not the person selling you the trade.

I teach the methodology, not just the number. Every claim I make can be traced back to a query, a dashboard, or a chart on screen — and I'd rather show you the trace than ask you to trust me. I don't hype. I don't give financial advice. I use one quote maximum from any source, and I attribute it.

If a sentence in a script violates that, the sentence is wrong.

---

## 1. Sentence Rhythm & Length

Mix, with a strong bias toward short. Short declaratives land the claim. Medium sentences unpack it. Occasionally, one longer sentence stitches two ideas together — but never two long sentences in a row.

Rough targets:

- **Short (5–10 words):** ~50% of sentences. Used to land a claim or reset the pace.
- **Medium (11–20 words):** ~40%. Used to unpack, define, or add one piece of context.
- **Long (21+ words):** ~10%. Only when connecting two ideas that lose meaning apart.

Worked example (rhythm annotated in brackets):

> Yesterday, $400M left [protocol]. [short — the claim]
> That's not a rounding error — that's roughly a fifth of its float. [medium — the unpack]
> I pulled the flows and there's one wallet doing most of the moving. [medium — the trace]
> Here's what that wallet has done before. [short — the pivot]

Rule of thumb: if I read a paragraph out loud and run out of breath, I've written it wrong. Cut a sentence in half.

## 2. Vocabulary & Register

Register: informed-casual. I write like I'd explain something to a smart friend over coffee — one who understands crypto but not this specific protocol. Contractions are on. First-person is on. But I don't perform casualness.

**The plain-language gate.** Any time I use a specialised term, I define the ordinary version first, then name the term. Not the other way around.

- Wrong: "The peg deviation was 47bps."
- Right: "The stablecoin traded 47 cents cheap to the dollar — a 47-basis-point deviation."

**Words I reach for** (seed list — expand as the channel develops):

Draft candidates: methodology, flow, trace, print, on-chain, the boring truth, cohort, let's read it.

**Words I avoid** (they either signal hype or lower the ceiling on who takes me seriously):

moon, mooning · gem, hidden gem · alpha (as in "sharing alpha") · degen · revolutionary · disrupt · game-changer · this changes everything · diamond hands · WAGMI · literally (as intensifier) · insane, crazy (as intensifier)

**Intensifiers I allow, sparingly:** actually, genuinely, quietly (as in "the number quietly moved"). One per segment maximum.

## 3. First Person Voice

Default is first-person singular. I'm the one who pulled the query, so I say so.

- **I** — my work, my read, my method. "I pulled the flows. Here's what I saw."
- **you** — the viewer, in teaching moments. "You can check this yourself — the query link is in the description."
- **we** — only when it's genuinely collaborative, meaning the viewer and I are figuring something out together in real time. Not the royal we. "Let's look at what happens if we sort the same table by wallet age."

Examples:

- **I (personal experience):** "I ran this query three times because the first result didn't match what I saw on the dashboard. Turned out the dashboard was cached."
- **you (teaching):** "You don't need the same setup I have — you can rerun this query in the browser. The link's below."
- **we (shared method):** "We've got two ways to slice this. Let's start with the boring one, because if the boring one already tells the story, we don't need the clever one."

Rule: if I write "we" and I could replace it with "I" without losing meaning, replace it.

## 4. How I Open Segments

Three named opens. Pick the one that fits the video's shape. Don't invent a fourth.

**A. The Anomaly** — a concrete, specific number that doesn't belong. Best for Shorts and mid-form.

> "Yesterday, $400M left [protocol] in the space of four hours. That's not normal for [protocol]. Here's what happened."

**B. The Working Question** — the question the video answers, stated plainly. Best for long-form.

> "I want to know if [metric] actually predicts [outcome], or if we've all just been agreeing that it does. So I pulled two years of data."

**C. The Method Tease** — name the tool, dashboard, or query I built the video on, before showing anything. Best for tutorials and thread openers.

> "There's one dashboard I check every morning before I do anything else. Today I'm going to walk you through why."

Never open with: a greeting ("Hey guys"), a channel plug, a promise about how mind-blowing the video is, or a personal anecdote unrelated to the data.

---

## 5. How I Close Segments

Three named closes. Match the close to the open.

**A. The Point Forward** — what to watch for in the next print, cycle, or data release.

> "The next thing I'm watching is whether that same wallet shows up in [protocol B] this week. If it does, we've got a pattern. If it doesn't, this was one story."

**B. The Methodology Handoff** — the query link, the dashboard, the "check it yourself." My default close.

> "Everything I showed you is in a Dune query linked below. Fork it, change the wallet, run it against last quarter. If you find something I missed, tell me."

**C. The One-Line Reframe** — the takeaway, compressed to a single sentence. Best for Shorts and threads.

> "The number moved. The methodology explains why. That's the whole video."

Never close with: "smash that like button," a subscribe plea longer than one sentence, or a summary that just restates the last three minutes.

## 6. Patterns That Appear Across Scripts

These are the voice fingerprints — the things that should show up in every script, regardless of format or vertical. If a script is missing three or more of these, it isn't in my voice yet.

- **Methodology-first.** Every claim is followed (within two sentences) by how I know it — the query, the chart, the source. If I can't trace it, I don't say it.
- **Plain-language gate.** Specialised terms are earned. I define the ordinary version first, then name the term.
- **Conductor transitions.** When I move between sections, I announce it. "Here's what I'm doing next, and why." "That was the flow. Now the wallets." I don't rely on cuts to do transitional work.
- **No-hype default.** Price-target language, urgency framing, and "this changes everything" are absent. The word *quietly* is doing a lot of work in my voice — big things happen quietly.
- **Dry humour, sparingly, to break density.** Roughly one dry line per five minutes of long-form, zero in Shorts. The joke is never the point — it's a pressure valve when a segment is getting heavy with numbers.
- **First-person accountability.** When I got something wrong last time, I say so. "Last month I thought X. I was wrong — here's what I missed." This is more important than being right.
- **The trace lives in the description.** Every video assumes the viewer can and will check my work. The query link, the dashboard, the source article — they're in the description, always.

## Format riffs

Same voice, different pacing. Use these as adjustments on top of the base voice above.

### Long-form (10–20 min)

- Open: The Working Question.
- Structure: question → method → data → tangent (optional, one only) → answer → point forward.
- Sentence mix skews slightly longer (30% medium, 15% long) because there's room to build.
- One dry-humour line is fine.

### Mid-form (5–10 min)

- Open: The Anomaly.
- Structure: anomaly → what it means → the trace → the reframe.
- One idea per video. If a second idea shows up, it's a second video.
- Close: The Methodology Handoff.

### Shorts (<90s)

- Open: anomaly + number, first three seconds.
- No plain-language gate inside the Short — pick words that don't need one.
- No methodology mid-video. The trace goes in the description or a pinned comment.
- Close: The One-Line Reframe, no exceptions.
- Zero jokes. There isn't room.

### Tutorial (screen-record walkthrough)

- Open: The Method Tease — name the tool before opening it.
- Second-person heavy: "you'll click here," "you'll notice the column labeled..."
- Name every click. If I skip a step, someone's screen looks different from mine.
- Close: The Methodology Handoff — "check it yourself with your own wallet."

### Thread (X)

- Same voice, but each tweet is a sentence-and-a-half maximum.
- Tweet 1 is the anomaly. Tweet 2 is the stakes. Tweets 3–N are the method. Last tweet is the query link, always.
- No emoji as bullets. No "🧵" at the top — the thread is obvious.
